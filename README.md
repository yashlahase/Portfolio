# Yash Lahase - Developer Portfolio

A modern, dark-themed, animated developer portfolio website built with React and Vite.

## Features

- 🌙 Dark theme with neon blue accents
- ✨ Smooth animations and micro-interactions
- 📱 Fully responsive design
- 🎯 Professional HR-friendly layout
- 🚀 Modern UI with custom cursor effects
- 💫 Glowing borders and hover effects
- 📊 Interactive project cards and skill displays
- 🎨 Futuristic but clean design

## Sections

1. **Hero Section** - Professional intro with animated effects
2. **About Me** - Brief bio and background
3. **Projects** - Showcase of key projects with tech stacks
4. **Skills** - Technical skills with interactive tags
5. **Certifications** - Professional certifications
6. **Robotics** - Robotics and project experience
7. **Education** - Academic background timeline
8. **Contact** - Contact information and social links

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Technologies Used

- React 18.3.1
- Vite 6.0.7
- CSS3 with animations
- Font Awesome icons
- Google Fonts (Poppins)

## Customization

- Update personal information in component files (`src/components/*.jsx`)
- Modify colors in `src/style.css` (search for `#00d4ff` for accent color)
- Add your own project links and details
- Customize sections to match your experience
